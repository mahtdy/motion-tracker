🧪 تست سیستم Error Handling

1️⃣ تست Browser Compatibility

بررسی می‌کنه که مرورگر از ویژگی‌های لازم پشتیبانی می‌کنه یا نه

2️⃣ تست Camera Error Classification

بررسی می‌کنه که خطاهای دوربین به درستی شناسایی می‌شن

3️⃣ تست Error Logging

بررسی می‌کنه که سیستم لاگ به درستی کار می‌کنه

4️⃣ تست Error Modal

نمایش انواع مختلف خطاها

روی دکمه‌ها بزن تا modal ها نمایش داده بشن

5️⃣ تست برنامه اصلی

اگر همه تست‌ها موفق بودن، برنامه اصلی رو باز کن
